# 🗞️ Fake News Detection System

## 📋 Overview
A comparative analysis of Machine Learning models for fake news detection, deployed as a web application.

## 🚀 Models Compared
1. **Logistic Regression** - Linear model for binary classification
2. **Naive Bayes** - Probabilistic classifier based on Bayes' theorem
3. **Passive Aggressive Classifier** - Online learning algorithm

## 📊 Features
- Real-time fake news detection
- Comparison across 3 models
- Ensemble voting for final verdict
- Confidence scores and probabilities
- Clean, professional UI
